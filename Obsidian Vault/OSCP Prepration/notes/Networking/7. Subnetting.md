# 7. Subnetting

### Subnetting Fundamentals

**Subnetting** is the process of dividing one IP network into multiple smaller logical networks called **subnets**.

Example:  
`192.168.1.0/24` → divided into four `/26` subnets.

---

### Why Subnetting Exists

Subnetting is used to:

- Reduce IP address wastage
- Separate network segments
- Reduce broadcast domains
- Improve network performance
- Apply security policies between segments
- Make routing more manageable

Example: separating **HR, Finance, Servers, and Users** into different subnets.

---

### Subnet Masks

A **subnet mask** identifies which bits belong to the network and which belong to hosts.

Example:

`255.255.255.0` = `/24`

- Network bits: 24
- Host bits: 8

---

### CIDR Notation

**CIDR (Classless Inter-Domain Routing)** represents the network prefix using `/number`.

Examples:

- `/24` → 24 network bits
- `/26` → 26 network bits
- `/30` → 30 network bits

Smaller prefix → larger network.  
Larger prefix → smaller network.

---

### Network Bits

Bits used to identify the **network/subnet**.

Example:

`192.168.1.0/24`

The first 24 bits are network bits.

---

### Host Bits

Bits remaining after the network prefix identify individual hosts.

For `/24`:

`32 - 24 = 8 host bits`

---

### Number of Subnets

When you borrow host bits for subnetting:

**Number of subnets = 2ⁿ**

`n` = number of borrowed bits.

Example:

`/24 → /26`

Borrowed bits = 2

`2² = 4 subnets`

---

### Number of Hosts

For IPv4:

**Usable hosts = 2ʰ − 2**

`h` = host bits.

Example `/26`:

`32 - 26 = 6 host bits`

`2⁶ - 2 = 62 usable hosts`

The two excluded addresses are normally the **network address** and **broadcast address**.

---

### Subnet Calculation

Subnet calculation determines:

- Network address
- Broadcast address
- Usable IP range
- Number of hosts
- Number of subnets

Example:

`192.168.1.0/26`

Subnet ranges:

- `192.168.1.0 – 63`
- `192.168.1.64 – 127`
- `192.168.1.128 – 191`
- `192.168.1.192 – 255`

---

### Network Address Calculation

The **network address** is the first address in a subnet and identifies the subnet itself.

Example:

`192.168.1.70/26`

belongs to:

`192.168.1.64/26`

So `192.168.1.64` is the network address.

---

### Broadcast Address Calculation

The **broadcast address** is the last address of the subnet and is used to reach all hosts within that subnet.

For `192.168.1.64/26`:

- Network: `192.168.1.64`
- Broadcast: `192.168.1.127`

---

### First/Last Usable Address

Normally:

- **First usable** = Network + 1
- **Last usable** = Broadcast − 1

For `192.168.1.64/26`:

- First: `192.168.1.65`
- Last: `192.168.1.126`

---

### VLSM

**VLSM (Variable Length Subnet Masking)** allows different subnet sizes within the same network.

Example:

- Servers → `/28`
- Employees → `/24`
- Point-to-point link → `/30`

It allows efficient IP address allocation based on actual requirements.

---

### FLSM

**FLSM (Fixed Length Subnet Masking)** gives every subnet the **same subnet size**.

Example:

`192.168.1.0/24 → four /26 subnets`

Every subnet has the same number of addresses.

---

### Supernetting

**Supernetting** combines multiple smaller networks into one larger address block.

Example:

`192.168.0.0/24`  
`192.168.1.0/24`  
`192.168.2.0/24`  
`192.168.3.0/24`

can be summarized as:

`192.168.0.0/22`

---

### Route Aggregation

**Route aggregation** combines multiple routes into a single summarized route.

Instead of advertising:

```
192.168.0.0/24
192.168.1.0/24
192.168.2.0/24
192.168.3.0/24
```

a router can advertise:

```
192.168.0.0/22
```

This reduces routing-table size and routing overhead.

---

### Subnetting Practice

For practical subnetting, you should be able to determine:

```
Given IP + Prefix
        ↓
Network Address
        ↓
Broadcast Address
        ↓
First Usable
        ↓
Last Usable
        ↓
Total/Usable Hosts
```

Example:

`10.10.10.130/26`

Result:

- Network: `10.10.10.128`
- Broadcast: `10.10.10.191`
- First: `10.10.10.129`
- Last: `10.10.10.190`
- Usable hosts: `62`

---

### Binary Subnetting

**Binary subnetting** calculates subnet boundaries by working directly with the binary representation of IP addresses and subnet masks.

It is useful for understanding exactly how subnet bits are borrowed.

---

### Decimal Subnetting

**Decimal subnetting** uses subnet-mask values and block sizes instead of manually converting everything to binary.

For practical networking, this is usually faster.

Example:

`/26 = 255.255.255.192`

Block size:

`256 - 192 = 64`

Therefore subnets occur at:

`0, 64, 128, 192`

---

### Subnetting for Network Segmentation

Subnetting is commonly used to logically separate network environments.

Example:

```
10.10.10.0/24
│
├── Users       → 10.10.10.0/26
├── Servers     → 10.10.10.64/27
├── Management  → 10.10.10.96/28
└── Security    → 10.10.10.112/28
```

Each subnet can have different **routing, firewall rules, ACLs, DHCP scopes, and security policies**.

**Key idea:** Subnetting is fundamentally about dividing an IP address space into controlled network boundaries.
