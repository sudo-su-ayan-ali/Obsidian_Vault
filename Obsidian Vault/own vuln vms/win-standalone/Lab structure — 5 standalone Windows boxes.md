### Lab structure — 5 standalone Windows boxes

| #   | Difficulty  | Theme (foothold)                                                                                                                                                | Privesc theme                                                                                              |
| --- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 1   | Easy        | Outdated/misconfigured web app on IIS (file upload → webshell, or known CVE in a bundled app like ManageEngine/Jenkins-on-Windows)                              | Weak service permissions (unquoted path or writable service binary)                                        |
| 2   | Easy–Medium | FTP/SMB anonymous access exposing creds or a config file → remote service login                                                                                 | Stored/reused credentials + `runas`/scheduled task abuse                                                   |
| 3   | Medium      | Vulnerable Windows service (custom TCP service or known CVE, e.g. old WinRM/old software with public exploit) → buffer overflow foothold _(optional, see note)_ | AlwaysInstallElevated or SeImpersonate (Juicy/PrintSpoofer-style, but without AD — local token abuse)      |
| 4   | Medium      | Web app with SQLi or deserialization bug → RCE as low-priv service account                                                                                      | Scheduled task running as SYSTEM with writable script/binary                                               |
| 5   | Medium–Hard | Chained: weak app exposes internal port only reachable after foothold (simulates pivoting without needing a second subnet) → second app vuln                    | Kernel exploit as last resort, but only after showing modern paths fail (patch it realistically otherwise) |
